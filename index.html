Jouer en ligne

Le mode en ligne a besoin d'un petit projet gratuit (Firebase) pour relayer les coups entre les deux téléphones. Ça se fait une fois, en 2 minutes, sans carte bancaire.

  1. Va sur console.firebase.google.com, connecte-toi avec un compte Google, clique Ajouter un projet.
  2. Dans le projet, ouvre Firestore Database → Créer une base de données → mode test (ça suffit pour un jeu entre amis).
  3. Va dans Paramètres du projet (icône ⚙️) → onglet Général → section "Vos applications" → clique l'icône </> Web pour créer une appli web.
  4. Copie l'objet firebaseConfig qui s'affiche et colle-le ci-dessous.

Cette config n'est pas un secret à protéger comme un mot de passe : c'est une adresse publique, la sécurité réelle vient des règles Firestore (pas besoin d'y toucher pour un jeu entre amis).

À toi de jouer
Règles rapides : on sème une graine par trou dans le sens anti-horaire. Si la dernière graine tombe dans un trou qui contenait déjà des graines, on ramasse tout ce trou (y compris la graine posée) et on continue à semer. On s'arrête quand la dernière graine tombe dans un trou vide : on remporte alors les graines du trou opposé, de l'autre côté du plateau. Si un camp n'a plus aucune graine à son tour, l'adversaire ramasse tout ce qu'il reste sur le plateau. L'anneau rose indique le dernier trou joué par chaque joueur.
